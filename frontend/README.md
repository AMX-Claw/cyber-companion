# Coral Baby - AI Pet Companion MVP

## 🎯 MVP Scope (Google for Startups申请用)

### 核心功能
- ✅ AI宠物陪伴（Gemini API驱动）
- ✅ 100天成长系统
- ✅ 多语言支持（中英文切换）
- ✅ 本地数据持久化
- ✅ 情感交互系统

### 技术栈
- Frontend: React 18 + Tailwind CSS
- AI: Google Gemini API (gemini-pro)
- Deployment: Cloudflare Pages / Vercel
- Storage: localStorage + IndexedDB

## 🚀 Quick Start

1. 获取Gemini API Key: https://makersuite.google.com/app/apikey
2. 在代码中配置API key（或通过环境变量）
3. 本地预览：直接打开index.html
4. 部署：上传到Cloudflare Pages
