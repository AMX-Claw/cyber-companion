## 冒险背包系统（v2 改版）

> 小玉 2026-04-29 原话："可以改成给小珂准备小背包，里面放吃的用的，就可以给延长小珂的🍼和心情。然后最低四小时才能接回，但是送出去时间越长越能发现valuable item。只能爸爸接，但是爸爸没接回来饥饿心情到0了就会哭哭回来。"

### 现有系统 vs 改版

| | 现在 | 背包版 |
|---|---|---|
| 出发条件 | 50金币 | 50金币 + 准备背包 |
| 状态衰减 | 正常衰减，hunger=0 探险失败 | 背包食物延缓 hunger 衰减 |
| 时长 | 固定 4h 最低 | 最低 4h，越久奖品越好 |
| 失败条件 | hunger=0 系统自动失败 | hunger=0 且 happiness=0 → 哭哭回来（无战利品） |
| 接回 | 爸爸接 | 只有爸爸能接 |
| 奖品 | 随机 loot | 时长分档：4h 普通 / 8h 稀有 / 12h+ 珍贵 |

### 背包机制

**POST /adventure/prepare** — 准备背包阶段
- 从 inventory 选食物放进背包（水果/蔬菜）
- 每份食物 +10 hunger buffer（出发后按正常速率衰减，先消耗 buffer）
- 背包上限 5 格
- 可选放入玩具（花/装饰品）→ +happiness buffer

**POST /adventure/start** — 出发（需要先 prepare）
- 扣 50 金币
- 记录 backpack 内容到 adventures 表（JSON）
- hunger_buffer / happiness_buffer 写入，冒险中衰减先扣 buffer

**奖品分档**
- 4-8h：普通（水果/蔬菜/花）
- 8-12h：稀有（家具/蛋）
- 12h+：珍贵（限定装饰品/特殊蛋色/新收集品）

**冒险中断联**
- 冒险中不能聊天/喂饭/洗澡/摸头，爸爸妈妈都不行
- 等爸爸接回来才能互动，增强"等她回家"的体验

**哭哭回来**
- hunger 和 happiness 都到 0 → status='cried_home'
- 不扣额外惩罚（她已经够可怜了）
- 回来后 hunger=5, happiness=5（不是 0，给个底）
- Gemini 生成"哭着回来"版日记

### DB 变动
- adventures 表加列：`backpack_json TEXT`、`hunger_buffer REAL DEFAULT 0`、`happiness_buffer REAL DEFAULT 0`
- 新 status 值：`preparing`（准备背包中）、`cried_home`（哭回来）
