# 2026-05-15 二胎 v2 — PUPi 素材 + 动画方案

## ⚠️ 小玉反馈（第三次，必须记住）

### 1. Gemini 素材不能用
Gemini 画的 MochiFox 六张表情图（idle/happy/sad/hungry/angry/sleepy）**每个状态画出来是不同的角色**，风格/比例/细节不统一。废弃。

### 2. 用 pupi reference.png（GPT 画的）
- 文件位置：`projects/xiaoke-project/pupi reference.png`
- GPT 画的角色设计书，叫 PUPi（鸡蛋糕）
- 白色圆团子，头顶粉色小草莓/桃子装饰
- 包含：6个表情（表情包行）、4个成长阶段、互动道具
- **处理方式**：去背景 + 从这张大图里截取各个表情/状态的单独 PNG

### 3. CSS 拉扯不算动画
一张静态 PNG 用 CSS scale/translate 做呼吸/弹跳，小玉明确说**不要**。已经告诉过三次了。
需要做的是真正的帧动画（spritesheet 翻帧）或分图层动画。
